# PAGEL Спеціальний Бетон — React

React-версія сайту PAGEL з компонентною архітектурою та React Router v6.

## Структура проєкту

```
src/
├── components/
│   ├── Header.jsx        — шапка з навігацією та мовним перемикачем
│   ├── HeroSlider.jsx    — hero-секція з автослайдером (5 слайдів, крапки, стрілки)
│   ├── ReferencesSlider.jsx — слайдер референцій з мініатюрами
│   └── Footer.jsx        — підвал із соціальними мережами та навігацією
├── pages/
│   └── HomePage.jsx      — головна сторінка
├── App.jsx               — маршрутизація
├── index.js              — точка входу
└── index.css             — глобальні стилі
```

## Запуск

```bash
npm install
npm start
```

## Збірка для продакшену

```bash
npm run build
```

## Особливості

- **HeroSlider** — 5 слайдів з фоновими фото PAGEL, автопрокрутка кожні 5 сек, крапки навігації знизу, стрілки ‹ ›
- **ReferencesSlider** — слайдер референцій з thumbnail-кнопками, аналог оригінального bb-design-slider
- **React Router v6** — всі внутрішні посилання через `<Link>` / `navigate()`
- Всі зовнішні посилання (pagel.com, possehl-construction.de) збережені без змін
- Адреси контактів, email, телефони — ідентичні оригінальному сайту
